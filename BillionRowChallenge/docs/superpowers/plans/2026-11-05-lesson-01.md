## Interfaces and implementation calls
Namespace BillionRows.Core. MeasurementGenerator.Generate(string path, long rowCount, int seed = 42) returns GenerationResult with RowCount, FileSizeBytes, Elapsed and RowsPerSecond. BaselineProcessor.Process(string path) returns ProcessingResult with Stations (IReadOnlyDictionary<string, StationStats>), RowCount, Elapsed, RowsPerSecond. BaselineProcessor.ParseLine(string line, long lineNumber = 1) returns (string Station, int TemperatureTenths). StationStats has MinTenths, MaxTenths, SumTenths, Count, Mean (decimal degrees), Add(int), constructor(int minTenths, int maxTenths, long sumTenths, long count) for valid aggregate state and overflow testing; ToString returns invariant min/mean/max with one decimal and AwayFromZero midpoint rounding.
Strict input: exactly one delimiter, nonempty valid UTF-8 station <=100 UTF-8 bytes, ASCII [-]digits.digit, -99.9..99.9, no whitespace/sign plus/exponent/thousands. File.ReadLines with strict UTF-8 decoder; accept CRLF and final unterminated line as documented convenience. Bound memory by stations plus longest input line; reject malformed records with line numbers. Generator uses seeded System.Random, integer tenths, buffered UTF-8 no BOM LF, FileMode.CreateNew to avoid destructive overwrite. Reproducibility scoped to pinned runtime/algorithm.
