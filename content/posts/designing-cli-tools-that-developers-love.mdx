A CLI is a user interface, even though it rarely gets treated like one. The tools people keep coming back to share a few traits: sensible defaults that work with zero flags, error messages that suggest the fix instead of just naming the problem, and output that stays readable whether it's a human reading a terminal or a script parsing JSON.

Progressive disclosure matters too. A new user should be able to run one command and get something useful; a power user should be able to drill into every flag without the tool getting in their way.

The best compliment a CLI can get isn't "it's powerful" — it's "I never had to read the docs."
