Imagine you are a new chef. You love cooking, but you are just starting out and don't have much experience yet. You want to create a recipe of your own, but you're not sure where to start.

A new chef might start with a simple recipe that has few ingredients and few steps. Minimal APIs work the same way. They let you build a web API with very little code and configuration. A few lines give you an endpoint that responds to HTTP requests, and you can grow from a "Hello World" message to an API that reads from a database.

You don't need years of experience to follow along. A basic understanding of programming is enough. Here is what you need to get started:

1.  An IDE or code editor. We will use Visual Studio Code, which is free and can be downloaded [here.](https://code.visualstudio.com/)

2.  The .NET 7 SDK, which you can download [here.](https://dotnet.microsoft.com/en-us/download/dotnet/7.0)

3.  Some knowledge of C#, the language we'll use. If you're new to C#, you can still follow this guide.

If everything is set up, run `dotnet --version` in your VS Code terminal. You should see the version of the .NET SDK you installed:

![](/images/blog/60f47311b3a8.png)

Now let's create our first Minimal API. Open your terminal and follow the steps below.

**Step 1:** Create a new project

In your terminal, go to the directory where you want to create your project. Then run the following command to create a new Minimal API project:

`dotnet new web -n CookingAPI`

This command creates an empty ASP.NET Core Minimal API called **CookingAPI**, with a single endpoint at the root path that returns "Hello World!".

**Step 2:** Add an endpoint

Open the project in your code editor (Visual Studio Code, or Rider in my case) and open the `Program.cs` file. This is where we'll define the routes and actions for our API.

Let's add an endpoint that returns a list of recipes. Put the following code in `Program.cs`:

```csharp
var builder = WebApplication.CreateBuilder(args);
var app = builder.Build();

app.MapGet("/recipes", () =>
{
    // list of recipes
    var recipes = new List<string>
    {
        "Patate Douce",
        "Bugali na Sombe",
        "Sambaza an chips"
    };

    return recipes;
});

app.Run();
```

The `MapGet` method defines a route for the `/recipes` endpoint. Inside the endpoint, you would normally fetch the recipes from a data source. To keep things simple, we hardcoded the list. In the next post, we will connect a database such as SQLite or Postgres.

**Step 3:** Run the API

Save your changes and go back to the VS Code terminal. From the root directory of your project, run:

`dotnet run`

This command builds and runs the API. Once it's running, open Postman or whichever tool you use to test APIs. In Postman, it should look like this:

![](/images/blog/d062e0f4d6fd.png)

Send a GET request to [http://localhost:5185/recipes](http://localhost:5185/recipes). Your port number may be different from mine, so use the one shown in your terminal. You should get back the list of recipes:

```csharp
[
    "Patate Douce",
    "Bugali na Sombe",
    "Sambaza an chips"
]
```

You have built your first API with Minimal APIs. From here, you can add more routes and actions, and connect the API to a database or other external services.

As in cooking, you get better with practice. Try different endpoints and data sources. In the next post, we'll connect the API to a database. When you're ready to go further, this gist covers more [advanced concepts](https://gist.github.com/davidfowl/ff1addd02d239d2d26f4648a06158727).

The source code for this introduction can be found [here](https://github.com/Dotnet-Community-DRC/CookingAPI).
