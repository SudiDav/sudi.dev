React Server Components asked me to unlearn a habit I'd built over a decade: reaching for `useEffect` any time a component needed data. Once components can simply be async and fetch what they need on the server, entire categories of loading-state bugs disappear.

The bigger shift is architectural. Instead of a single client bundle that fetches everything through an API layer, you get a tree where server and client components interleave, each fetching exactly what it owns, exactly where it's rendered.

It took a few projects before this stopped feeling unfamiliar, but now going back to a client-only data-fetching model feels like giving up information the framework already had.
