Hello everyone, I trust you're all doing well. Today, we're going to send an email from an ASP.NET Core Minimal API using MailKit, starting from an empty project.

I'll assume you have the .NET SDK and an Integrated Development Environment (IDE) installed. For this post, I'm using the [.NET 7 SDK](https://dotnet.microsoft.com/en-us/download/dotnet/7.0) and [JetBrains Rider](https://www.jetbrains.com/rider/download/#section=mac), which is a paid product with a one-month free trial. You can also use [Visual Studio Code](https://code.visualstudio.com/) or [Visual Studio 2022 Community](https://visualstudio.microsoft.com/vs/), which are both free.

**Step 1. Create a new project**

Create a new ASP.NET Core Web API project from the terminal. Open the terminal, use the `cd` command to go to your preferred directory, and run:

`dotnet new webapi -o SendingEmail`

This scaffolds a new Web API project that we'll use as our starting point. Since we are working with Minimal APIs, we don't need the `Controllers` folder or the `WeatherForecast` class, so delete them.

**Step 2. Define the email data transfer object (DTO)**

We need a data transfer object (DTO) to carry the email data from our API to the mail server, which then sends the email to the recipient.

Create a folder called `Models` in the project directory, and add a class named `EmailDto` with the following properties:

```csharp
namespace SendingEmail.API.Models;

public class EmailDto
{
    public string From { get;  set; }
    public string To { get;  set; } 
    public string  Subject { get;  set; } 
    public string Body { get;  set; }
}
```

**Step 3. Create the email service interface**

Create a folder named `Services` in the project root, and add an interface called `IEmailService`:

```csharp
namespace SendingEmail.API.Services;

public interface IEmailService
{
    Task SendEmailAsync(EmailDto request);
}
```

The interface is the contract for our email service. Any class that sends email for the API implements it. Before writing that class, add the MailKit package. From the project root, run:

`dotnet add package MailKit`

Now add the implementation. Create an `EmailService` class in the `Services` folder:

```csharp
using MailKit.Net.Smtp;
using MailKit.Security;
using MimeKit;
using MimeKit.Text;

namespace SendingEmail.API.Services;

public class EmailService : IEmailService
{
    private readonly IConfiguration _config;
    public EmailService(IConfiguration config)
    {
        _config = config;
    }
    public async Task SendEmailAsync(EmailDto request)
    {
        var email = new MimeMessage(); 
        email.From.Add(MailboxAddress.Parse(request.From));
        email.To.Add(MailboxAddress.Parse(request.To));
        email.Subject = request.Subject;
        email.Body = new TextPart(TextFormat.Html) {Text = request.Body};

        using var smtp = new SmtpClient();
        await smtp.ConnectAsync(_config["EmailHost"], 587, SecureSocketOptions.StartTls);
        await smtp.AuthenticateAsync(_config["EmailUsername"], _config["EmailPassword"]);
        await smtp.SendAsync(email);
        await smtp.DisconnectAsync(true);
    }
}
```

**Step 4. Configure the API endpoint**

With the email service in place, we'll create an endpoint that uses it to send email. We map a POST route at `/email`:

```csharp
//...
app.MapPost("/email", (EmailDto request, IEmailService emailService) =>
{
    emailService.SendEmail(request);
    return Results.Ok();
});
// ...
```

The endpoint receives the request body and the injected email service. Here is the full `Program.cs`, including the registration of the `IEmailService` interface and its `EmailService` implementation:

```csharp

global using SendingEmail.API.Services;
global using SendingEmail.API.Models;

var builder = WebApplication.CreateBuilder(args);

builder.Services.AddControllers();
builder.Services.AddEndpointsApiExplorer();
builder.Services.AddSwaggerGen();
builder.Services.AddScoped<IEmailService, EmailService>();

var app = builder.Build();

if (app.Environment.IsDevelopment())
{
    app.UseSwagger();
    app.UseSwaggerUI();
}

app.UseHttpsRedirection();

app.UseCors();

app.UseAuthorization();

app.MapControllers();

app.MapPost("/email", (EmailDto request, IEmailService emailService) =>
{
    emailService.SendEmailAsync(request);

    return Results.Ok();
});
app.Run();
```

This maps HTTP POST requests on the `/email` route. When a request arrives, the app calls the `SendEmailAsync` method on our email service with the data from the request body.

**Step 5. Set up the application configuration**

The application needs SMTP settings to send email. We store them in the `appsettings.json` file:

```csharp
{
  "Logging": {
    "LogLevel": {
      "Default": "Information",
      "Microsoft.AspNetCore": "Warning"
    }
  },
  "EmailHost": "smtp.ethereal.email",
  "EmailUsername": "rosamond.schoen50@ethereal.email", 
  "EmailPassword": "R8fARwUE7PHFHXuvrZ",
  "AllowedHosts": "*"
}
```

We use Ethereal, a fake SMTP service, for testing. It accepts the email so you can confirm the application sends it, but it never delivers it to the recipient.

Create a free account on [Ethereal](https://ethereal.email/). Ethereal gives you a username and password. Put them in `appsettings.json`.

**Step 6. Test with Swagger**

The Web API template comes with Swagger already configured, so we can test the endpoint from the browser without extra tools such as Postman.

Start the application, either with the run button in Rider or with `dotnet run` in the terminal. Then open [https://localhost:\{yourPort\}/swagger/index.html](https://localhost:5001/swagger/index.html) in your browser.

On the Swagger page, find `POST /email` and click `Try it out`. Fill in the request body with the JSON for an email DTO, with values for From, To, Subject, and Body, then click `Execute`. Swagger sends a POST request to the `/email` endpoint the same way any client would, and shows you the response. A 200 response code means the email was submitted. You can then open your Ethereal inbox to see the message.

**Conclusion**

In this post, we sent an email from an ASP.NET Core Minimal API using MailKit. We created a project, defined a DTO for the email data, and wrote an email service interface with a MailKit implementation.

We then added a POST endpoint at `/email` that clients call to send email, and configured the SMTP host, username, and password, which you can change for your own email provider.

Many APIs need to send email, for example to confirm an account or reset a password. Now you can add it to yours. Happy coding! 🙏🏾
