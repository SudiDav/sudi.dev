The things we’d explain if we were setting it up next to you on the sofa.

What is Stremio?

Stremio is the app you use to browse your library and play videos. Addons provide catalogs, subtitles, and sources. Your invitation helps set up those addons on your account.

Do I need to share my password?

Never send passwords or API keys in a message. When invitations are enabled, review the account connection before approving it. The family manager can update the addons connected to your account.

Which quality should I choose?

Try a smaller 1080p file first. Larger 4K files need a faster connection. Resolution and file size both affect how smoothly a video plays.

Does this include streaming subscriptions?

No. Access to this family setup does not include Netflix, Disney+, or other subscriptions. Use sources you have permission to watch.
